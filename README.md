# FaceFit-AI
FaceFit AI: A Camera-Based Eyewear Compatibility and Recommendation System Using Facial Feature Analysis

## Repository layout

- [`kiosk/`](kiosk/README.md): Android kiosk application, including camera capture, face landmark detection, facial feature extraction, and kiosk artwork.
- [`mobile/`](mobile/): Android mobile application.
- [`web/admin/`](web/admin/README.md): Web administration dashboard.

Open each application from its own folder. For kiosk development, open `kiosk/` in Android Studio.
